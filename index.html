Observability Platform

Full-stack observability for react-springboot-mysql. Metrics, logs, distributed traces, log-template anomalies, and AI-assisted root-cause analysis — Terraform on AWS for the monitoring + application stack, the AI layer on a dedicated AWS g5.xlarge GPU host in us-west-2 (A10G, Tailscale-attached). What makes it different: an MCP-only hallucination firewall that doubles as a backend portability seam (swap Prometheus / Loki / Jaeger for Zabbix / Elasticsearch / Tempo by writing one MCP bridge), zero-code OpenTelemetry instrumentation for most polyglot stacks, a 14-archetype exemplar library, and 3+ months of operational track record incl. a same-day GPU migration (789-test suite; real-load median ~38 s end-to-end on the new runner with qwen2.5:14b). Proof of concept on a local test bed, asking for CIRES production greenlight — see Solution Brief.
